# UpFunnels no Cursor

Plugin para o Cursor. Aponta para o MCP de produção e traz as skills de uso.

Servidor: `https://mcp.upfunnels.com/mcp`

Em Configurações → Customize → MCP, use esse endereço. Na primeira conexão, autorize no navegador. A organização é a escolhida nessa tela. Não há client id nem secret neste repositório.

## Skills

- `conectar` — liga o cliente ao servidor
- `crm` — contatos, leads e números
- `atendimento` — conversas e envio de texto
- `funis` — funis, páginas e domínios
- `funcionario-ia` — funcionários de IA e bases de conhecimento

O plugin não substitui o app da UpFunnels.
