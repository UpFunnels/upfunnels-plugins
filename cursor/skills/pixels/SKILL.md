# Pixels

Use só estas ferramentas: `list_pixels`, `get_pixel`, `create_pixel`, `update_pixel`, `delete_pixel`, `link_pixel_funnels`, `unlink_pixel_funnel`.

Não peça nem grave segredo, token ou chave.

- `list_pixels` lista os pixels.
- `get_pixel` lê um pixel pelo id.
- `create_pixel` cria um pixel.
- `update_pixel` atualiza nome, status ou código do pixel.
- `link_pixel_funnels` vincula funis a um pixel.
- `unlink_pixel_funnel` desvincula um funil. Não apaga o pixel.

Antes de `delete_pixel`, peça confirmação ao usuário. `delete_pixel` apaga o pixel.
